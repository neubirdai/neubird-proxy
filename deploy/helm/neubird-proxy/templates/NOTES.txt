{{- if .Values.tunnel.joinTokenEnv }}

With the join token ({{ .Values.tunnel.joinTokenEnv }} in Secret {{ .Values.env.existingSecret }}), the proxy
enrolls its own key: nothing to send NeuBird. Once you see "enrolled with the
join token" or "key already enrolled", remove it (it can't be used again):

   kubectl -n {{ $ns }} patch secret {{ .Values.env.existingSecret }} --type=json \
     -p '[{"op":"remove","path":"/data/{{ .Values.tunnel.joinTokenEnv }}"}]'

If enrollment is refused (token expired or already used), ask NeuBird for a
new token, or send them the key's fingerprint instead:
{{- else }}

Send NeuBird the key's fingerprint (not secret; the key never leaves this
cluster); the tunnels come up once NeuBird records it:
{{- end }}

   kubectl -n {{ $ns }} exec deploy/{{ $deploy }} -- \
     /neubird-proxy fingerprint /etc/neubird-proxy/tunnel/tunnel.key

Test the tunnel and each system from inside a pod (no request is sent):

   kubectl -n {{ $ns }} exec deploy/{{ $deploy }} -- /neubird-proxy test -config /etc/neubird-proxy/config.yaml
